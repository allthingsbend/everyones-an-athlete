# Everyone’s an Athlete Astro Site

Production domain: https://everyonesanathlete.app
App link: https://app.hhmovement.com

## Deploy to GitHub + Cloudflare Pages

1. Unzip this folder.
2. Upload the folder contents to a new GitHub repository.
3. In Cloudflare Pages, connect the GitHub repository.
4. Use these build settings:
   - Framework preset: Astro
   - Build command: npm run build
   - Build output directory: dist
5. Add the custom domain: everyonesanathlete.app

## Notes

- Sitemap is generated by Astro.
- Canonical URLs use https://everyonesanathlete.app.
- Robots.txt points to the production sitemap.
- Main navigation is built around the four app pillars: Training, Body Care, Mindset, and Fuel & Wellness.
